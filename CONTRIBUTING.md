# Как внести вклад

Спасибо за интерес к проекту. Ниже — короткие правила, чтобы изменения было легко проверять.

## Ветки

- `main` — стабильные релизы;
- `dev` — текущая разработка. Пул-реквесты — в `dev`.

## Требования к изменениям

1. Один PR — одно логическое изменение.
2. Перед отправкой обязательно зелёный `npm run verify` (`tsc` + ESLint + Jest).
3. Поведение существующих сценариев не меняется без явного описания в PR.
4. Не добавляйте чувствительные данные (токены, cookies, реальные адреса порталов, персональные данные) — ни в код, ни в тесты, ни в логи.

## Коммиты

Формат — Conventional Commits:

```
<type>(<scope>): <краткое описание>
```

Типы: `feat`, `fix`, `refactor`, `test`, `docs`, `chore`.

## Тесты

Тесты выполняются только с моками — без реальных сетевых запросов к порталу.

```bash
npm test
npm run verify
```
